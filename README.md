# UAV Object Detection using YOLO & Faster R-CNN

A collaborative deep learning project for detecting objects in aerial UAV imagery. It contains a custom YOLO implementation in PyTorch and a Faster R-CNN experiment, using the VisDrone dataset.

## Project files

- `yolo_uav_training.ipynb` — custom YOLO model, training, and evaluation
- `faster_rcnn_uav_experiment.ipynb` — Faster R-CNN comparison

## Requirements

Python with PyTorch, Torchvision, Matplotlib, OpenCV, NumPy, and Pillow. The notebooks were developed for Google Colab and expect the VisDrone dataset to be available in Google Drive; update the dataset paths for your environment.

## Run

Open either notebook in Jupyter or Google Colab and run its cells. Download and prepare the VisDrone dataset before training.
